# Pós-Venda Porto

Sistema de pós-venda com importação de planilhas Excel por cabeçalho.

## Publicar no GitHub Pages

1. Envie o arquivo index.html para a raiz do repositório.
2. Em Settings → Pages, selecione Deploy from a branch.
3. Selecione a branch main e a pasta / (root), e clique em Save.
4. Acesse o endereço informado pelo GitHub Pages.

## Uso

Clique em Importar base Excel e selecione sua planilha de contratos.
Os dados ficam salvos no navegador. Não envie planilhas com dados de clientes ao repositório.
É necessária conexão com a internet para carregar as bibliotecas de Excel.
